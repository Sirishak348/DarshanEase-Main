🛕 DarshanHub

DarshanHub is a temple booking and pilgrimage management web application that helps devotees explore temples, book darshan tickets, manage bookings, and download tickets online.

✨ Features

🔐 User Registration & Login
🛕 Temple Search & Exploration
🎟️ Online Darshan Booking
📋 My Bookings
📄 PDF Ticket Generation
👤 User Profile
⭐ Feedback & Reviews
🤝 Partner With Us
👨‍💼 Admin Dashboard
👥 User & Booking Management
🛕 Temple Management
📱 Responsive Design
